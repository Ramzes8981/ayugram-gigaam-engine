# AyuGram ASR v0.7.0 — экспериментальная версия (Android ARM64)

**Статус:** код плагина собран и проверен статически; установщик протестирован на настоящем архиве ARM64 и отрицательных сценариях. **Загрузка всего движка и распознавание на стоковом Android ещё не подтверждены** (был успешен только тест небольшого `ctypes.CDLL`-модуля). Прежде чем включать на основном телефоне, проверьте на тестовом устройстве. APK AyuGram и root не меняются.

## Установка

1. Сделайте репозиторий `Ramzes8981/ayugram-gigaam-engine` публичным после проверки исходников и истории коммитов. До этого GitHub Release недоступен анонимному телефону.
2. Убедитесь, что [публикация engine-v1.0.0](https://github.com/Ramzes8981/ayugram-gigaam-engine/actions/workflows/publish-engine-release.yml) завершилась успешно. Если не запустилась автоматически, выберите **Run workflow** вручную. Артефакт исходной сборки удалится 18 октября 2026, поэтому Release следует опубликовать до этой даты.
3. Скачайте [ayugram_asr_v0.7.0.plugin](../plugins/ayugram_asr_v0.7.0.plugin) из GitHub и импортируйте в AyuGram вместо v0.6.2. ID плагина сохранён, старые GGUF остаются на месте.
4. В настройках **AyuGram ASR** нажмите **Установить / восстановить движок**, дождитесь сообщения «Движок успешно установлен без root».
5. Скачайте **GigaAM E2E RNNT Q4** прямо в разделе «Модели», выберите её в выпадающем списке и включите локальную расшифровку. Если модель уже установлена, повторная загрузка не нужна.
6. Протестируйте несколько голосовых последовательно. Проверяйте очередь и состояние в настройках.

## Версии и защита

- Движок: [engine-v1.0.0](https://github.com/Ramzes8981/ayugram-gigaam-engine/releases/tag/engine-v1.0.0), `transcribe.cpp` commit `95d82e5134fba4b18ad6a46f3baf950f53bcfc3b`.
- Архив: `engine-arm64-v8a.zip` (в составе `libtranscribe.so`, `libggml-base.so`, `libggml-cpu.so`, `libggml.so`, `SHA256SUMS`, `VERSION.txt`).
- **Закреплённый SHA-256 архива:** `8f310e6c89e924550715e4d16a5459478999bbee707d546f102a66ccbeeb55e9`. Установщик сверяет его с HTTPS-суммой Release и самим скачанным ZIP, затем проверяет каждую библиотеку, формат ARM64 ELF, commit и загрузку через `ctypes.CDLL`.
- Библиотеки ставятся в версионированную папку внутри `code_cache/asr_engine`. Путь переключается после успешной валидации. Старые ручные установки не удаляются.
- Текущие модели сохраняются; GGUF не входят в этот архив. Телефон с root не обязателен.

## Что изменилось по сравнению с v0.6.2

- Движок загружается и устанавливается самим плагином из официального Release, без ADB и root.
- Один главный экран: состояние движка, загрузка, все три модели с размерами и состояниями, активная модель, очистка модели с подтверждением, очередь.
- Отладочные панели и A/B перехват скрыты/отключены в пользовательской версии.
- Остаются FIFO-очередь обычных голосовых до 8 ожидающих и оптимизированное объединение чанков.

## Ограничения и диагностика

- Первую установку нельзя провести офлайн; после установки движок и модели работают локально.
- Первая сборка предназначена только для `arm64-v8a` / Android API 26+; зависимые native `.so` могут по-разному загружаться на разных версиях AyuGram.
- GitHub должен быть доступен в сети телефона; в РФ для GitHub/Hugging Face иногда требуется VPN.
- Прогресс, видимый в настройках, обновляется при повторном открытии экрана; окончание установки и ошибка выводятся в диалоге.
- Если установка не сработала, пришлите текст диалога целиком и модель телефона/версию Android. Не нужно отправлять чужие голосовые или переписки.
